\section{Software Layers}

The firmware is divided into two distinct layers, isolating hardware-independent from hardware-specific logic:  

\begin{itemize}
    \item \textbf{Blue Layer (Drivers / HAL)}: handles direct hardware interaction and abstraction.
    \item \textbf{Red Layer (Application / Components)}: contains the AOCS-specific logic.
\end{itemize}
