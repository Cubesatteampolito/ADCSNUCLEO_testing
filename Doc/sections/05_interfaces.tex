\section{Internal Interfaces}
Data is exchanged via FreeRTOS Queues: 

\emph{i) \textbf{IMUQueue1}, \textbf{IMUQueue2}}: Send sensor data from the IMU Task to the Control and OBC tasks. 

\emph{ii) \textbf{setAttitudeADCSQueue}}: Sends target attitude data from the OBC Task to the Control Task. 

\emph{iii) \textbf{ADCSHouseKeepingQueue}}: Sends current and temperature telemetry fromthe Check Task to the OBC Task

\emph{iv) \textbf{SetOpModeADCSQueue}}: Used to change the operational mode (Idle, Control, Test)

\section{External Interfaces}
UART and SPI
