\subsection{FreeRTOS Configuration}
In \texttt{FreeRTOSConfig.h}, key configuration parameters are: 
\begin{itemize}
    \item \texttt{configUSE\_PREEMPTION}: 1 (Enables preemptive scheduling)
    \item \texttt{configTICK\_RATE\_HZ}: 1000 (Scheduler frequency)
    \item \texttt{configMINIMAL\_STACK\_SIZE}: 128
    \item \texttt{configTOTAL\_HEAP\_SIZE}: 3000
\end{itemize}
The \texttt{Heap 4} memory management model is adopted.
